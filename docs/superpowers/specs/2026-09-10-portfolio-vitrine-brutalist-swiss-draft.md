# Portfolio Vitrine — Brutalist × Swiss Draft

Status: draft — awaiting user approval before implementation.

This note records the requested direction only; it is not yet an implementation spec.

- Portfolio remains a pure showcase: no `Créer mon site`, no funnel, no brief form, no purchase or adaptation CTA.
- Visual direction to resolve: hybrid Brutalist × Swiss, with strict grid discipline, raw typographic contrast, hard rectangular framing, real demo previews, no SaaS-card aesthetic.
- Available demo previews should open the demo in a new browser tab/window so the portfolio remains open.
- Internal navigation inside each demo remains in that demo tab.
- Portfolio descriptions must describe the actual design direction of each demo accurately and concretely, not make sales promises or generic marketing claims.
- Kuro and Maison Silex remain independent design systems and must not be restyled by the portfolio refresh.
- Remaining templates continue one by one, each with its own design spec and 5/7 differentiation gate.
