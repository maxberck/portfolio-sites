# Garage 03 — Relais 24 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build and publish `garage-03` as a complete five-route roadside-assistance portfolio template with a distinct Relais 24 identity, a generated portfolio preview, and dedicated smoke/CI verification.

**Architecture:** Follow the existing demo-site pattern: route files under `app/sites/garage-03/**` render focused page components from `src/templates/garage-03/**`; shared data, theme tokens, header/footer and secondary hero live inside the template. Portfolio publication is handled by `src/portfolio/data/sites.ts` plus the generated WebP preview. Verification starts with a failing smoke contract, then the implementation makes that contract green.

**Tech Stack:** Next.js 16.3.4, React 19.2.8, TypeScript 5, CSS, GitHub Actions, Node smoke scripts.

**Spec:** `docs/superpowers/specs/2026-09-11-garage-03-relais-24-design.md`

## Global Constraints

- Brand: `Relais 24`, a fictional roadside-assistance and rapid-diagnostic service around Brussels.
- Palette: Night Blue `#0B1320`, Road Slate `#1E2935`, Asphalt `#2C3138`, Safety Orange `#FF6B1A`, Reflective Cream `#F4F1E8`, Utility Grey `#9DA6AD`.
- Five routes only: home, `depannage`, `diagnostic`, `remorquage`, `contact`.
- No backend, booking, dispatch tracking, geolocation, online payment, fake reviews, fake certifications, guaranteed arrival times, iframe, or form.
- Every demo page must be `noindex, follow`.
- Do not modify the visual systems of `garage-01` or `garage-02`.
- Responsive, keyboard-accessible navigation, visible focus states, practical touch targets, reduced-motion support, no horizontal overflow.
- Use realistic everyday roadside/tow/diagnostic photography, not supercars, tuning, motorsport, or luxury-dealership imagery.
