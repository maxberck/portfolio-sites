# Coiffure 03 — Form Studio Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build and publish `coiffure-03` Form Studio as a five-route contemporary hair salon demo using a Swiss functional grid, typographic service tables, architectural photography, generated portfolio preview, and dedicated CI smoke coverage.

**Architecture:** Follow the repository pattern of thin Next.js App Router files under `app/sites/coiffure-03/**` and template-owned data, types, components, pages, theme and stylesheet under `src/templates/coiffure-03/**`. Keep the site fully static and visually isolated from Maison Élise and District Cut. Publication happens only after route/content checks are green, then `/public/previews/coiffure-03-home.webp` is generated through the existing preview workflow.

**Tech Stack:** Next.js 16.3.4 App Router, React 19.2.8, TypeScript 5, CSS, `next/font/google`, `next/image`, Node smoke scripts, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-09-11-coiffure-03-form-studio-design.md`

## Global Constraints

- Brand: `Form Studio`.
- Direction: Swiss functional / modern hair salon.
- Palette: off white `#F3F2ED`, black `#111111`, cool gray `#B7BAB7`, line gray `#D9DAD6`, acid green `#C7FF32` used only as a small wayfinding accent.
- Routes: `/sites/coiffure-03`, `/services`, `/studio`, `/work`, `/contact`.
- Desktop primary navigation is a thin horizontal header, never a side rail.
- Every route inherits `robots: { index: false, follow: true }`.
- No backend, booking engine, live availability, account, payment, form, iframe, embedded map, geolocation, fake reviews, awards, founder story or unverifiable claims.
- Services are ruled typographic rows, not repeated cards.
- Work uses strict 2/3–1/3 and 1/3–2/3 image compositions, not masonry randomness.
- Photography must remain hair/salon-specific and avoid District Cut barber imagery or Maison Élise romantic beauty imagery.
- Existing Garage, Restaurant, Maison Élise and District Cut product files remain untouched except shared portfolio verification counts when publication legitimately changes them.
- Accessibility: semantic headings, keyboard navigation, visible `:focus-visible`, adequate contrast, practical touch targets, non-color active cues and reduced-motion support.
- Final publication requires `public/previews/coiffure-03-home.webp` generated by the repository capture workflow.
