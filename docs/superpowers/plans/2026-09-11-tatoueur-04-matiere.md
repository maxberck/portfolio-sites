# Tatoueur 04 — Matière Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build and publish `tatoueur-04` Matière as a five-route contemporary art-book tattoo studio demo with asymmetric editorial compositions, route-specific SEO, responsive folio navigation, browser-level image/layout regression tests, and a real portfolio preview.

**Architecture:** Keep the demo isolated under `src/templates/tatoueur-04/**` and expose it through thin App Router files under `app/sites/tatoueur-04/**`. Core content is typed and server-rendered, with navigation implemented as semantic links rather than a client-heavy shell. Dedicated smoke and Playwright checks gate publication before the registry moves from `planned` to `available`.

**Tech Stack:** Next.js 16 App Router, React 19, TypeScript, repository-native CSS/Tailwind 4 stack, `next/image`, GitHub Actions, Playwright Chromium.

**Spec:** `docs/superpowers/specs/2026-09-11-tatoueur-04-matiere-design.md`

## Global Constraints

- Keep the identity exactly **Matière** with direction **Contemporain / artistique**.
- Keep all production implementation isolated in `src/templates/tatoueur-04/**` plus thin `app/sites/tatoueur-04/**` route files.
- Do not import UI, data or CSS from `tatoueur-01`, `tatoueur-02` or `tatoueur-03`.
- Do not redesign the portfolio shell.
- No backend, CMS, authentication, booking engine, form workflow, map iframe, payment flow, ratings, awards or fake certifications.
- All five routes must export unique Next.js `Metadata` and inherit `robots: { index: false, follow: true }`.
- Core content stays server-rendered and crawlable.
- Desktop uses a quiet right-edge folio index; mobile uses an inline Contents block with no fixed navigation.
- No gradients, glassmorphism, rounded SaaS cards, conventional multi-column footer or generic card grids.
- Imagery must be both technically valid and semantically tattoo/studio/body/gesture related.
- Before writing production code, read the current relevant Next.js 16 documentation available to the environment; if project-local `node_modules/next/dist/docs/` is not available through the connector workflow, verify the corresponding current official Next.js documentation and keep route APIs aligned with existing repo patterns.
- Do not claim NaCl or Superdesign runtime verification unless those runtimes are actually available and executed.
