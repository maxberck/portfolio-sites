# Coiffure 01 — Maison Élise Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build and publish the `coiffure-01` Maison Élise demo as a five-route premium hair-salon site with a distinct editorial beauty system, generated portfolio preview, and dedicated CI smoke contract.

**Architecture:** Follow the repository pattern of thin Next.js App Router files in `app/sites/coiffure-01/**` and template-owned data, components, pages, theme and stylesheet in `src/templates/coiffure-01/**`. Keep the site fully static: contact links may work, but there is no booking engine, backend, checkout, account system, live availability, form or embedded map. Publish only after the route/content contract is green, then generate `/public/previews/coiffure-01-home.webp` through the existing capture workflow.

**Tech Stack:** Next.js 16.3.4 App Router, React 19.2.8, TypeScript 5, CSS, `next/font/google`, `next/image`, Node smoke scripts, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-09-11-coiffure-01-maison-elise-design.md`

## Global Constraints

- Brand: `Maison Élise`.
- Direction: `Maison beauté éditoriale`.
- Palette: warm ivory `#F3EEE7`, espresso `#2B211D`, skin beige `#D7C3B6`, muted burgundy `#6A2F3C`, warm white `#FCFAF7`, utility grey `#7B716C`.
- Routes: `/sites/coiffure-01`, `/prestations`, `/maison`, `/galerie`, `/contact`.
- Every route inherits `robots: { index: false, follow: true }` from the template layout.
- No backend, booking calendar, form, iframe, checkout, account, live availability, fake reviews, fake awards, fake press logos or e-commerce catalogue.
- Photography must show salon craft, hair texture, styling, consultation or salon atmosphere; avoid generic fashion/glamour imagery where hair is not the subject.
- Layout must use asymmetric editorial composition and varied image ratios rather than repeated equal cards.
- Existing Garage, Restaurant and later Coiffure template visual systems remain untouched.
- Accessibility: semantic heading order, descriptive alt text, visible `:focus-visible`, sufficient contrast, approximately 44px practical touch targets and `prefers-reduced-motion` support.
- Final publication requires `public/previews/coiffure-01-home.webp` generated by the existing preview workflow.
