# Coiffure 02 — District Cut Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build and publish the `coiffure-02` District Cut demo as a five-route urban barber site with a persistent desktop side rail, poster-like asymmetrical layouts, generated portfolio preview, and dedicated CI smoke contract.

**Architecture:** Follow the repository convention of thin Next.js App Router files under `app/sites/coiffure-02/**` and template-owned data, types, components, pages, theme and stylesheet under `src/templates/coiffure-02/**`. Keep the site fully static and isolated from Maison Élise: no shared visual components or CSS. Publication happens only after the route/content contract is green, then `/public/previews/coiffure-02-home.webp` is generated through the existing capture workflow.

**Tech Stack:** Next.js 16.3.4 App Router, React 19.2.8, TypeScript 5, CSS, `next/font/google`, `next/image`, Node smoke scripts, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-09-11-coiffure-02-district-cut-design.md`

## Global Constraints

- Brand: `District Cut`.
- Direction: `Brutal street barber`.
- Palette: Coal `#111111`, Near Black `#080808`, Steel `#9A9A94`, Bone `#EEEAE1`, Signal Red `#C9302C`, Concrete `#3A3A38`.
- Routes: `/sites/coiffure-02`, `/services`, `/shop`, `/cuts`, `/contact`.
- Desktop primary navigation is a persistent vertical side rail; mobile converts it into a compact accessible top navigation.
- Every route inherits `robots: { index: false, follow: true }` from the template layout.
- No backend, appointment engine, calendar, live availability, payment, account/login, form, iframe, embedded map, geolocation, fake reviews, fake awards or fake customer transformation claims.
- Photography must show barbering, haircut detail, clippers/tools, beard work, shop interior or strong haircut-focused portraits; unrelated fashion photography must not drive the site.
- Services render as a linear barber menu, never a repeated equal-card grid.
- The Cuts page is an illustrative visual gallery and must not imply the photos document real District Cut customers.
- Existing Garage, Restaurant and Maison Élise product files remain untouched.
- Accessibility: semantic headings, keyboard navigation, visible `:focus-visible`, sufficient contrast, approximately 44 px practical tap targets and `prefers-reduced-motion` support.
- Final publication requires `public/previews/coiffure-02-home.webp` generated by the repository preview workflow.

- [ ] **Step 1: Write the smoke script before product code**

Use these route markers:

```js
const pages = [
  ["/sites/coiffure-02", "CUT CLEAN. STAY SHARP."],
  ["/sites/coiffure-02/services", "Services"],
  ["/sites/coiffure-02/shop", "The Shop"],
  ["/sites/coiffure-02/cuts", "Cuts"],
  ["/sites/coiffure-02/contact", "Contact"],
];
```

For every route assert HTTP 200, `name="robots" content="noindex, follow"`, no `<form` and no `<iframe`. On home require links to all four child routes and the markers `FADE`, `BARBE`, `COUPE + BARBE`, `CONTOURS`. On `/categories/coiffure`, require `data-site-card="coiffure-02"`. When `COIFFURE02_REQUIRE_AVAILABLE === "1"`, also require `coiffure-02-home.webp` in category HTML and `public/previews/coiffure-02-home.webp` on disk.

Use this structure:

```js
const base = process.env.BASE_URL ?? "http://127.0.0.1:3000";

for (const [path, marker] of pages) {
  const response = await fetch(`${base}${path}`);
  if (!response.ok) throw new Error(`${path}: expected 200, received ${response.status}`);
  const html = await response.text();
  if (!html.includes(marker)) throw new Error(`${path}: missing marker ${marker}`);
  if (!html.includes('name="robots" content="noindex, follow"')) throw new Error(`${path}: missing noindex, follow`);
  if (/<iframe\b/i.test(html)) throw new Error(`${path}: iframe forbidden`);
  if (/<form\b/i.test(html)) throw new Error(`${path}: form forbidden`);
}
```
