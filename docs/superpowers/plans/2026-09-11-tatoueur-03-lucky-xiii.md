# Tatoueur 03 — Lucky XIII Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build and publish `tatoueur-03` Lucky XIII as a five-route old-school tattoo shop demo with a flash-book architecture, route-specific SEO, responsive booklet navigation, browser-level image/layout regression tests, and a real portfolio preview.

**Architecture:** Keep the demo isolated under `src/templates/tatoueur-03/**` and expose it through thin App Router files under `app/sites/tatoueur-03/**`. Core content is typed and server-rendered; only the navigation may use client state if needed. Dedicated smoke and Playwright checks gate publication before the registry is switched to `available`.

**Tech Stack:** Next.js 16 App Router, React 19, TypeScript, Tailwind/CSS 4, `next/image`, GitHub Actions, Playwright Chromium.

**Spec:** `docs/superpowers/specs/2026-09-11-tatoueur-03-lucky-xiii-design.md`

## Global Constraints

- Keep the identity exactly **Lucky XIII** with direction **Old school / vintage**.
- No imports from `tatoueur-01` or `tatoueur-02`.
- No backend, CMS, auth, booking engine, forms, map iframe, reviews, fake awards or fake certifications.
- All five routes use unique `Metadata` and inherit `robots: { index: false, follow: true }`.
- Template remains copyable: typed content data, template-local CSS, thin routes.
- Desktop structure must use storefront masthead + printed flash-book language; no left rail or white-cube minimal nav.
- Mobile must become a vertical booklet/leaflet composition with no fixed bottom nav.
- Final imagery must be both technically valid and semantically tattoo-related.
- `tatoueur-04` remains `planned` throughout.
