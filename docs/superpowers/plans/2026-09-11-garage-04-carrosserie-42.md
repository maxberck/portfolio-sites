# Garage 04 — Carrosserie 42 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build and publish the `garage-04` Carrosserie 42 demo as a five-route bodywork/paint workshop site with its own visual system, generated portfolio preview, and Garage 04-specific CI contract.

**Architecture:** Follow the established repo pattern: thin Next.js route files in `app/sites/garage-04/**`, template-owned components/pages/data/styles in `src/templates/garage-04/**`, a dedicated smoke script and GitHub Actions workflow, then minimal portfolio publication through `src/portfolio/data/sites.ts` and `preview-target.json`. Keep all demo behavior static and presentational; no backend, forms, booking, insurer integration, live tracking, or fake customer proof.

**Tech Stack:** Next.js 16.3.4 App Router, React 19.2.8, TypeScript 5, CSS, Node smoke scripts, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-09-11-garage-04-carrosserie-42-design.md`

## Global Constraints

- Brand: `Carrosserie 42`.
- Direction: `Cabine peinture / fiche de remise en état`.
- Palette: `#E9E4D8`, `#F7F4EC`, `#171817`, `#A8AAA6`, `#B94A3A`, `#7F3028`, `#C8C3B8`.
- No gradients, shadows, generic repeated cards, tuning/racing/luxury-dealer styling, fake reviews/certifications/pricing/insurer links/booking/forms/tracking.
- Routes: `/sites/garage-04`, `/carrosserie`, `/peinture`, `/realisations`, `/contact`.
- Every page uses `noindex, follow` metadata through the Garage 04 layout.
- Existing Garage 01/02/03 and restaurant templates must remain unchanged.
- Accessibility: semantic headings, alt text, focus-visible, contrast, accessible mobile navigation, reduced-motion support, ~44px touch targets.
- Final publication requires `public/previews/garage-04-home.webp` generated by the existing preview workflow.
